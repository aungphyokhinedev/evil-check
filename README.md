# How Evil Are You?

A playful Dark Triad Yes/No quiz (Machiavellianism, Narcissism, Psychopathy) with reverse scoring and a shareable result image.

**English UI · Myanmar questions · Entertainment only — not a clinical assessment.**

## Run

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scoring

- Direct question: Yes = +1, No = 0
- Reverse (`isReverse: true`): Yes = 0, No = +1
- Total: 0–50, plus per-trait breakdown
